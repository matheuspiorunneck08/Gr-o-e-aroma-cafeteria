# Grão & Aroma — Site Institucional

Site institucional da **Grão & Aroma**, cafeteria artesanal localizada em São Paulo. Desenvolvido com HTML, CSS e JavaScript puros, publicado via GitHub Pages.

🔗 **[Acesse o site ao vivo](https://matheuspiorunneck08.github.io/Gr-o-e-aroma-cafeteria/)**

---

## Páginas

| Arquivo | Descrição |
|---|---|
| `index.html` | Página inicial — hero, destaques do cardápio, galeria e horários |
| `cardapio.html` | Cardápio completo com categorias: cafés especiais, bebidas e comidas |
| `sobre.html` | História da marca, valores e processo do grão à xícara |
| `contato.html` | Endereço, horários, como chegar e contato via WhatsApp |

## Tecnologias

- **HTML5** semântico
- **CSS3** — variáveis customizadas, Flexbox, Grid, animações
- **JavaScript** — Intersection Observer (animações de entrada), menu mobile, smooth scroll
- **Google Fonts** — Playfair Display + Lato

## Funcionalidades

- Design responsivo (mobile-first)
- Navbar com efeito scroll e menu hamburger para mobile
- Animações de entrada com Intersection Observer
- Seções: hero, split layout, galeria mosaico, destaques do cardápio
- Integração WhatsApp e Instagram

## Como rodar localmente

Não precisa de servidor. Abra `index.html` diretamente no navegador:

```bash
# Opção 1: abrir direto
start index.html

# Opção 2: com servidor local (recomendado)
npx serve .
```

## Estrutura

```
grao-e-aroma/

├── sobre.html       # Nossa história
```
